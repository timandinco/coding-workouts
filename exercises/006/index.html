Exercise 006: The Tag Counter

Focus: The .reduce() method and object manipulation.

The Task:

You have a list of blog posts, and each post has an array of tags. You need to create a single object that counts how many times each tag appears across all posts.

  1. Use .reduce() (or a loop if you prefer) to iterate through the posts.
  2. Flatten the tags into a count.
  3. The keys of the resulting object should be the tag name, and the value should be the frequency.

Examples

Input:

        const posts = [
            { title: "Post 1", tags: ["php", "web"] },
            { title: "Post 2", tags: ["javascript", "web"] },
            { title: "Post 3", tags: ["php", "backend"] },
            { title: "Post 4", tags: ["web", "frontend"] }
        ];

Output:

{ php: 2, web: 3, javascript: 1, backend: 1, frontend: 1 }
