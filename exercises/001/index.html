Exercise 001: Unique Filter

You have an array of user IDs that contains duplicates. Write a function that returns a new array containing only the unique IDs, sorted in ascending order.

Example

  • Input: [105, 102, 105, 101, 102, 108]
  • Expected Output: [101, 102, 105, 108]

  return [...new Set(userIds)].sort((a, b) => a - b);
This line of JavaScript does two main things:
  1. Removes duplicates from the `userIds` array using `new Set(userIds)`, which creates a `Set` object (a collection of unique values).
  2. Sorts the unique values numerically using `.sort((a, b) => a - b)`, which sorts the array in ascending order.
The spread operator `[... ]` converts the `Set` back into an array.

How You Might Have Done This 10 Years Ago (Pre-ES6)

Before ES6 (2015), JavaScript didn't have Set, arrow functions, or the spread operator. Here's how you might have achieved the same result:

1. Remove Duplicates

You could use a loop to filter out duplicates:

var uniqueUserIds = [];
for (var i = 0; i < userIds.length; i++) {
  if (uniqueUserIds.indexOf(userIds[i]) === -1) {
    uniqueUserIds.push(userIds[i]);
  }
}

2. Sort Numerically

The sort method existed, but you'd need to pass a comparator function using the function keyword:

uniqueUserIds.sort(function(a, b) {
  return a - b;
});

Combined Example

Here's the full pre-ES6 version:

var uniqueUserIds = [];
for (var i = 0; i < userIds.length; i++) {
  if (uniqueUserIds.indexOf(userIds[i]) === -1) {
    uniqueUserIds.push(userIds[i]);
  }
}
uniqueUserIds.sort(function(a, b) {
  return a - b;
});
return uniqueUserIds;

Key Differences

  • Set: Introduced in ES6 to simplify creating collections of unique values.
  • Arrow Functions: Introduced in ES6 for concise syntax.
  • Spread Operator: Introduced in ES6 to easily convert iterables (like Set) into arrays.
Here's how you might have written this logic in **JavaScript 10 years ago (pre-ES6, ~2014)**, along with alternatives from other eras and frameworks:

1. Pre-ES6 (2014 and earlier)

As mentioned, you'd use a loop to remove duplicates and a function for sorting:

// Remove duplicates
var uniqueUserIds = [];
for (var i = 0; i < userIds.length; i++) {
  if (uniqueUserIds.indexOf(userIds[i]) === -1) {
    uniqueUserIds.push(userIds[i]);
  }
}

// Sort numerically
uniqueUserIds.sort(function(a, b) {
  return a - b;
});

return uniqueUserIds;

Note:

  • indexOf was the standard way to check for duplicates.
  • var was used instead of let/const.

2. Early ES5 (2009-2014)

If you wanted to be slightly more concise, you could use Array.prototype.filter (introduced in ES5):

// Remove duplicates using filter
var uniqueUserIds = userIds.filter(function(id, index) {
  return userIds.indexOf(id) === index;
});

// Sort numerically
uniqueUserIds.sort(function(a, b) {
  return a - b;
});

return uniqueUserIds;

Note:

  • filter + indexOf was a common pattern for deduplication.

3. Using Libraries (e.g., jQuery or Lodash)

If you were using Lodash (a popular utility library), you could simplify it:

// Using Lodash
var uniqueUserIds = _.uniq(userIds);
uniqueUserIds = _.sortBy(uniqueUserIds, function(id) {
  return id;
});
return uniqueUserIds;

Note:

  • Lodash's _.uniq removes duplicates.
  • _.sortBy sorts the array numerically.

4. Using Underscore.js (Another Popular Library)

// Using Underscore.js
var uniqueUserIds = _.uniq(userIds);
uniqueUserIds = _.sortBy(uniqueUserIds, function(id) {
  return id;
});
return uniqueUserIds;

5. ES6+ (2015 and Later)

This is the modern version you shared:

return [...new Set(userIds)].sort((a, b) => a - b);

6. TypeScript (Modern Alternative)

If you were using TypeScript, it would look similar to ES6 but with type annotations:

const uniqueUserIds: number[] = [...new Set(userIds)];
return uniqueUserIds.sort((a, b) => a - b);

7. Functional Programming Style (Pre-ES6)

If you preferred a functional approach, you might use reduce:

var uniqueUserIds = userIds.reduce(function(acc, id) {
  if (acc.indexOf(id) === -1) {
    acc.push(id);
  }
  return acc;
}, []);

uniqueUserIds.sort(function(a, b) {
  return a - b;
});

return uniqueUserIds;

Key Takeaways

  • Pre-ES6: Loops, indexOf, and function were the norm.
  • ES5: filter and reduce became more common.
  • Libraries: Lodash/Underscore simplified array operations.
  • ES6+: Set, arrow functions, and spread operator made it concise.
