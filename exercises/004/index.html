Exercise 004: The User Data Sanitizer

Focus: Array methods (reduce, filter), template literals, and basic math.

The Task: Write a function calculateTotal(cart, discountCode) that:

  1. Calculates the subtotal of all items (price * quantity).
  2. If the discountCode is "SAVE10", apply a 10% discount to the total.
  3. If the subtotal is over $100, provide free shipping ($0); otherwise, add a flat $5 shipping fee.
  4. Output: Return a string formatted as: "Total: $XX.XX (including $X shipping)".

];
