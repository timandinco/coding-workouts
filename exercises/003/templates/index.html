Exercise 003: Product Stock Report

Focus: filter, map, reduce, basic string formatting

The Task:

You are given an array of products. Each product has:

  1. name
  2. price
  3. inStock
Keeps only products where inStock is true. Creates a new array of strings in this format: 
"Notebook - \$4.50"

Calculates the total price of all in-stock products.

Return or log both:
  • the formatted array
  • the total

Examples

Input:

const products = [
  { name: "Notebook", price: 4.5, inStock: true },
  { name: "Pen", price: 1.2, inStock: false },
  { name: "Backpack", price: 25.0, inStock: true },
  { name: "Pencil", price: 0.8, inStock: true }
];

Output:

            [
  "Notebook - \$4.50",
  "Backpack - \$25.00",
  "Pencil - \$0.80"
]
