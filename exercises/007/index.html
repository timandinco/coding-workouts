Exercise 007: The Newsletter Cleanup

Focus: Array methods (map, filter, sort) and the Set object (or manual deduplication).

The Task:

You have a messy list of subscriber emails collected from a form.

  1. Clean: Remove whitespace from the start/end of each email and convert them all to lowercase.
  2. Unique: Remove any duplicate email addresses.
  3. Sort: Sort the final list alphabetically.
  4. Return the cleaned array.

Examples

Input:

const rawEmails = [
    "  Alice@example.com", 
    "bob@test.com  ", 
    "ALICE@example.com", 
    "  charlie@provider.net", 
    "bob@test.com"
];

Output:

["alice@example.com", "bob@test.com", "charlie@provider.net"]
