Exercise 005: JavaScript (The Admin Formatter)

Focus: Array methods (filter, map, sort) and string manipulation.

The Task:

You are given an array of user objects.

  1. Extract only the users who have the role "admin".
  2. Clean up the usernames: ensure they are trimmed of whitespace and the first letter is capitalized (Title Case).
  3. Sort the resulting list of names alphabetically.
  4. Return the final array of strings.
If you go over time:

If either of these takes longer than 20 minutes, don't sweat it! Stop and consult these specific topics:
PHP: array_filter() vs. foreach loops and the implode() function.
JavaScript: Method chaining (e.g., .filter().map().sort()) and String methods like .trim() and .slice().

Examples

Input:

          const users = [
            { username: "  alice smith ", role: "admin" },
            { username: "bob jones", role: "user" },
            { username: "  charlie brown", role: "admin" },
            { username: "david johnson", role: "user" }
          ];

Output:

["Alice", "Charlie", "Dave"]
